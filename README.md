# Resenha — versões

Aqui ficam os instaladores do Resenha para Windows.

**Para instalar:** abra **Releases** (à direita), baixe o `Resenha-Setup-x.y.z.exe` da versão mais nova e abra.
No aviso do Windows, clique em **Mais informações → Executar assim mesmo**.

Depois de instalado, o Resenha se atualiza sozinho.
